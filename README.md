# Cadre commun du mode produit

Représentation du cadre commun du mode produit de la sous-direction projets produits (SNUM), sous la forme d'une ville en huit quartiers.

- **Carte interactive** : `index.html`. Cliquez sur un quartier pour voir son contenu et ses connexions, filtrez par rôle, naviguez avec les flèches du clavier.
- **Version à plat** : `Cadre-commun-mode-produit-A3.pdf` (A3 paysage, pour l'impression) et `Cadre-commun-mode-produit-A3.png` (pour une présentation). Elle est aussi accessible depuis la page, onglet « Version à plat ».

La page est autonome : un seul fichier HTML, sans dépendance à installer.
